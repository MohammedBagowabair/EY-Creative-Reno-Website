# EY Creative Reno & Designs — website concept

Bilingual (English / Bahasa Melayu) one-page concept for EY Creative Reno & Designs, Wangsa Maju, Kuala Lumpur.
Vite + React + TypeScript + Tailwind. Portfolio and job photos are from EYCR's own public Instagram accounts (@eycrstudio, @eycraircond), each linked to its post; map © OpenStreetMap contributors.

- Dev: `npm install && npm run dev`
- Build for GitHub Pages: `BASE_PATH=/EY-Creative-Reno-Website/ npm run build`
- Images: put sources in `src-images/` and run `node scripts/img.mjs`
